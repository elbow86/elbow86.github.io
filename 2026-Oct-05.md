# WSL Docker experiments and AI workflow notes

A few small experiments from today, all in the spirit of learning by doing.

## 1. Docker Immich in WSL

I set up Docker Immich in WSL and spent time testing the container flow, storage assumptions, and overall local experience. It was a useful reminder that self-hosting photo tools in WSL can work well when the networking and volume setup are kept simple.

## 2. Docker NextCloud in WSL

I also tried Docker NextCloud in WSL. This was a similar experiment, but with a different goal: a self-hosted file-sync and collaboration environment. It is a good sandbox for understanding how containerized app stacks behave when you want a personal cloud replacement without a full VM or hosted service.

## 3. Mistral Vibe (free) for the subscription tracker

I also used Mistral Vibe (free tier) to help brainstorm and shape new features for my subscription tracker. 

## 4. Karpathy's ASD-STE100 rules idea

I also tried the idea from Karpathy's recent post about ASD-STE100 rules analysis. The prompt was essentially:

> randomly sample 10 session transcripts where I worked with you interactively within the past week; apply ASD-STE100 rules to assistant responses; analyze which rules would have increased clarity, reduced confusion, and improved the conversations.

This was a useful experiment in reflective AI practice. The value was not only in scoring output quality, but in identifying what kinds of conversational patterns actually create confusion in real sessions. In other words, it turns the issue from "did the assistant answer correctly?" into "where did the communication get fuzzy, and which rules would smooth it out?"

That is the kind of review I want to keep doing: not as a checklist, but as a way to make AI interactions clearer and more grounded.
